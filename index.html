Linear Algebra with Python

A free, open textbook that starts from the geometry of linear mappings, develops the theory with full proofs, and uses Python to compute, verify and draw each idea.

Read the book Try an experiment in Colab Source on GitHub

  • 11 chapters, from sets and vectors through determinants, eigenvalues and inner product spaces to the singular value decomposition and quantum mechanics.
  • 13 hands-on experiments: 2D and 3D linear maps, Gaussian elimination, Markov chains, the Bloch sphere, eigenfaces, PCA. They run in Colab or Binder with nothing to install. This site shows the text, code and saved output; the sliders need a live Jupyter kernel.
  • Exercises with expandable solutions and Python checks for most chapters.

By An-Sheng Jhang and Ping-Zen Ong. This is the English edition.
